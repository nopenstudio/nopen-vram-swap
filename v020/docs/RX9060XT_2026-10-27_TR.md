## v0.2 prioritized engineering gates

1. Hardware residency and topology: AMDGPU VRAM/GTT counters during allocation, PCIe width/speed, CPU and OpenCL driver; validate allocations are physically in VRAM.
2. Bulk throughput: pinned host staging, larger DMA batches, bounded queue depth and multiple in-flight buffers. Repeat at larger pool sizes.
3. Random faults: 4KiB p50/p95/p99 latency, prefetch/clustered-page predictions, strict read/write integrity, application profiling. A large 4MiB transfer is not suitable for every random fault.
4. RAM economics: baseline Alpha.5 64MiB CPU maxRSS=67804KiB, OpenCL pager maxRSS=107768KiB (+39964KiB); net RAM savings unproven. Account for pinned host memory, driver RSS, GPU memory budget, and reclaim pressure.
5. NVMe/zram/zswap comparison on identical random and sequential workloads; do not describe bulk GPU bandwidth as app-usable swap rate.
6. GNU-free NopenOS: freestanding C11 page policy stays separate; Linux/glibc/OpenCL benchmark and userfaultfd adapter are not yet NopenOS runtime.
7. Kernel safety: GPU reset recovery, memory reclaim forward progress, no NBD, no global swapon; prior NBD swap caused PID1 crash.
