# v0.8 — SIGBUS diagnostics (work in progress)

**Status: experimental, raw-block only. Real SWAP must remain disabled.**

The v0.5 experiment terminated with `SIGBUS` at 2026-10-25 20:49:23. The NBD connection died and read/write failures followed. The cause of the original signal is not yet established.

The v0.7 raw-block test passed on an AMD gfx1200 GPU with 2048 MiB allocated, but this does not validate real SWAP reliability.

## v0.8 planned verification

- Preserve the user's 2048 MiB minimum allocation.
- Capture faulting instruction address, fault address, signal code, and last GPU-transfer phase.
- Save process memory mappings for later address-to-library resolution.
- Instrument slow OpenCL transfers and enforce locked host buffers.
- Run independent 4 KiB random reads/writes with Linux O_DIRECT.
- Do not activate swap or use this as memory for Bannerlord until failures are resolved.

**Note:** This status document does not claim that v0.8 source code has been pushed to GitHub yet. The source package is built separately for local testing and should be reviewed before it is committed.
